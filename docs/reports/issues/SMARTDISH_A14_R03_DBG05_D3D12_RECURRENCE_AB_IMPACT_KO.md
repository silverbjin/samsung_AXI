## Educational lesson
A previous PASS is evidence of a particular run, not universal absence of intermittent faults. Compare immutable ancestry and first failing process before assigning fault. Separate code regression from host state and workload-triggered exposure. Hardware validation requires same hardware; Xvfb software is not WSLg proof. Do not repeat already valid ST-02 physics solely for GUI debugging.
